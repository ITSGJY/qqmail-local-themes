# QQ邮箱本地主题切换

适用于新版 QQ 邮箱的 Tampermonkey 用户脚本，提供 **东方青绿、竹林清风、桃花微雨** 三种主题，支持记住选择、跟随网页设置和控制台诊断。

脚本通过修改页面主题 CSS 类名，应用 QQ 邮箱提供的样式与背景资源。主题选择保存在 Tampermonkey 中。

## 安装与更新

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [脚本源文件](./qqmail-local-themes.user.js)，复制完整代码到 Tampermonkey 新脚本中保存。
3. 打开或刷新 [QQ 邮箱](https://wx.mail.qq.com/home/index)。
4. 点击浏览器工具栏中的 Tampermonkey 图标，在脚本菜单中选择主题。

更新时，用最新代码替换已有脚本并保存，然后刷新邮箱。

## 使用

- **东方青绿、竹林清风、桃花微雨**：选择后立即应用，当前选项带勾选标记。
- **跟随网页设置**：停止本地换肤并刷新页面，恢复邮箱自己的主题。
- **输出诊断信息到控制台**：生成当前主题状态的诊断快照。

脚本监听页面主题类的变化，在网页重新设置类名后恢复所选主题。

## 控制台诊断

按 F12 打开开发者工具的 Console（控制台），启用 Info、Warning、Error 级别，筛选 `QQ邮箱本地主题`。日志前缀包含脚本版本，例如 `[QQ邮箱本地主题 v2.2.0]`。

建议勾选 Preserve log（保留日志），以保留「跟随网页设置」刷新前的记录。

| 日志事件 | 含义 |
| --- | --- |
| `startup` | 脚本启动及当前选择 |
| `theme-selected` | 切换前后的选择及保存结果 |
| `theme-applied` | 应用主题前后的 CSS 类名 |
| `theme-repaired` | 网页覆盖主题后的恢复情况 |
| `follow-page` | 切换到网页设置并准备刷新 |
| `diagnostic` | 当前状态的诊断快照 |
| `theme-check-inconclusive` | 主题类或背景层需要进一步检查 |

读取或保存偏好失败、菜单 API 缺失、菜单注册失败及主题应用失败，会输出对应的警告或错误事件。

`theme-repaired` 最多每 10 秒输出一次；累计修复次数和省略的日志条数保留在诊断快照中。

### 诊断快照

在脚本菜单中选择「输出诊断信息到控制台」可手动生成快照。页面启动、恢复显示及切换主题后，也会延迟约 1.5 秒自动检查。

快照包含：

- 当前选择、页面加载状态、主题类匹配结果。
- 背景层数量、声明了背景图片样式的层数。
- 主题应用次数、覆盖修复次数及省略的日志条数。
- 页面主体绑定次数、菜单数量及 GM API 可用性。

诊断信息在本地控制台输出，内容限于主题结构、状态和计数。

### 排查问题

1. **没有启动日志**：确认脚本已启用、保存后刷新了邮箱，并检查控制台的日志级别和筛选条件。
2. **出现保存失败提示**：当前页面仍可切换主题；刷新后可能恢复为上次成功保存的选择。
3. **出现 `theme-check-inconclusive`**：等待页面加载完成，再手动输出一次诊断信息。
4. **主题类正确但外观异常**：结合 Network 面板检查背景资源请求，并查看页面实际显示效果。诊断中的背景层计数只检查 CSS 声明，图片下载和渲染需要另行确认。
5. **频繁出现修复日志**：检查网页主题设置、其他换肤脚本或扩展是否反复修改主题类。

提交问题时，请提供脚本版本、浏览器与 Tampermonkey 版本、复现步骤，以及带有上述前缀的日志。附图前请遮挡邮件和个人信息。

## 兼容性

适用地址：`https://wx.mail.qq.com/home/index*`。

主题依赖 QQ 邮箱现有的 `page-theme-*` CSS、背景层结构和图片资源。网页更新改变这些内容时，可能需要调整脚本。诊断日志可用于定位类名、页面结构或资源加载问题。
